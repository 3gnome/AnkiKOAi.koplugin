# Images for the README

Drop screenshots / a screen recording here using these exact filenames so the
README "Demo" section renders them automatically:

| File | What it should show | Notes |
|------|---------------------|-------|
| `demo.gif` | Full flow: long-press a word or highlight a passage → **AnkiKOAi** menu → card preview → the finished card in Anki | The most important asset. Keep it short (5–15s) and under ~5 MB so it loads on GitHub. |
| `highlight-menu.png` | The selection menu showing the **AnkiKOAi** / **Memorization** entries | From the emulator or a device screenshot. |
| `card-preview.png` | A generated card preview (Wiki Card or Vocabulary Card) | |
| `anki-card.png` | The same card shown in desktop Anki | Demonstrates the end result. |

## Tips for capturing

- The desktop emulator is easiest for clean screenshots: `bash start.sh --emulator alice.epub`
- For a GIF on Windows, use ScreenToGif or ShareX; on macOS, Kap.
- Crop tightly and avoid showing any real API keys or your LAN IP.
- PNGs for stills, GIF (or MP4 linked separately) for the demo.

Once these files exist, commit them and the README images will appear.
