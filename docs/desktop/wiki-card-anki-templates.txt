================================================================================
Anki note type name:  Wiki Card
Plugin menu label:    Wiki Card (AI)

Card layout:  FRONT = highlighted term only
              BACK  = Wikipedia-style article + related Wikipedia links

Open this file in any text editor on your computer (Notepad, VS Code, etc.).
Copy each block below into Anki → Tools → Manage Note Types → Wiki Card → Cards.

Formatted guide with deck options:  docs/anki-vocabulary.md
On e-reader (View README):           docs/in-app/wiki-card.md

================================================================================
PART 1 — FIELDS (in this order)
================================================================================
  Phrase
  Text
  Links
  Source
  Definition
  IPA
  Synonyms

Delete default Front/Back. Keep one card type (Card 1).

If upgrading an older note type, add the Links field (Tools → Manage Note Types
→ Wiki Card → Fields → Add → Links).

PART 5 — DECK (suggested)
================================================================================
Create deck:  English::Koreader
Plugin default deck and note type must match Anki.

Suggested deck-options preset name:  Wiki Card

  New cards/day:              20–40
  Maximum reviews/day:        200
  Learning steps:             1m 10m 1d
  Graduating interval:        3 days
  Easy interval:              7 days
  Starting ease:              250%
  Lapse steps:                10m
  Leech threshold:            8
  Bury related new/siblings:  OFF

Wiki Cards are content-heavy — higher daily limits than memorization step cards
are usually fine.

Full setup guide (fields, plugin settings, custom note types):
  docs/anki-vocabulary.md
